# 模型与数据许可证说明 / Model and Dataset License Notes

## 中文

ForgeX 本仓库不包含任何第三方模型权重，也不授予你使用第三方模型或数据集的额外权利。

使用 ForgeX 时，你需要自行确认：

- 基座模型是否允许商用、再分发、微调和导出；
- 数据集是否允许训练、再发布和商业使用；
- API 服务是否允许用输出内容训练其他模型；
- 生成的 LoRA、GGUF、Ollama 模型是否能公开发布。

建议在每个导出的模型目录中保留模型来源、数据来源、训练参数和许可证说明。

---

## English

This repository does not include third-party model weights and does not grant additional rights to use third-party models or datasets.

When using ForgeX, you are responsible for checking whether:

- the base model allows commercial use, redistribution, fine-tuning, and export;
- the dataset allows training, republication, and commercial use;
- the API provider allows using outputs to train other models;
- the generated LoRA, GGUF, or Ollama model can be publicly released.

It is recommended to keep model sources, dataset sources, training parameters, and license notes in every exported model directory.
